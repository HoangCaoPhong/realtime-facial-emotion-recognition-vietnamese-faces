========================================
1. PROJECT OVERVIEW
========================================

Project Name: VN-FER-Realtime
Vietnamese Facial Emotion Recognition in Real-Time

Purpose:
A deep learning computer vision application designed to recognize and classify
emotional expressions on Vietnamese faces in real-time using a webcam. The
project uses a pre-trained CNN model optimized for facial emotion recognition.

What the Project Does:
- Captures live video feed from webcam
- Detects faces using Haar Cascade classifier
- Extracts facial regions and preprocesses them (resize to 64x64, normalize)
- Predicts emotion class (7 emotions) using a trained Keras/TensorFlow model
- Displays bounding boxes and emotion labels with confidence scores on live video

Main Features:
1. Real-time face detection and emotion classification
2. Modular architecture (emotion model, webcam app, utilities)
3. Pre-trained CNN model supporting 7 emotion classes
4. Live visualization with confidence scores
5. Optimized for Vietnamese facial features (noted as future work)

Main Entry Points:
- demo/run_webcam.py: Main application entry point (starts real-time emotion detection)
- training/finetune_vn.py: Training script for fine-tuning model (currently empty/placeholder)

Expected Inputs/Outputs:
Inputs:
  - Live video stream from webcam (RGB frames)
  - Pre-trained model weights (model/emotion_model.h5)
Outputs:
  - Real-time video with detected faces and emotion predictions
  - Emotion labels with confidence scores displayed on frames

FILE: models/emotion_model.py
LANGUAGE: python
==============================
import numpy as np
from tensorflow.keras.models import load_model

INPUT_SIZE = (64, 64)
EMOTION_LABELS = [
    "Angry",
    "Disgust",
    "Fear",
    "Happy",
    "Sad",
    "Surprise",
    "Neutral"
]

class EmotionModel:
    def __init__(self, model_path: str):
        self.model = load_model(model_path, compile=False)

    def predict(self, face_tensor):
        """
        face_tensor shape: (1, 64, 64, 1)
        """
        preds = self.model.predict(face_tensor, verbose=0)
        idx = int(np.argmax(preds))
        return EMOTION_LABELS[idx], float(preds[0][idx])

FILE: app/webcam_app.py
LANGUAGE: python
==============================
import cv2
import numpy as np
from models.emotion_model import INPUT_SIZE

class WebcamApp:
    def __init__(self, emotion_model):
        self.emotion_model = emotion_model
        self.face_cascade = cv2.CascadeClassifier(
            cv2.data.haarcascades + "haarcascade_frontalface_default.xml"
        )
        self.cap = cv2.VideoCapture(0)

    def preprocess_face(self, gray_frame, x, y, w, h):
        face = gray_frame[y:y+h, x:x+w]
        face = cv2.resize(face, INPUT_SIZE)
        face = face.astype("float32") / 255.0
        face = np.reshape(face, (1, INPUT_SIZE[0], INPUT_SIZE[1], 1))
        return face

    def run(self):
        while True:
            ret, frame = self.cap.read()
            if not ret:
                break

            gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
            faces = self.face_cascade.detectMultiScale(
                gray,
                scaleFactor=1.3,
                minNeighbors=5
            )

            for (x, y, w, h) in faces:
                face_tensor = self.preprocess_face(gray, x, y, w, h)
                emotion, conf = self.emotion_model.predict(face_tensor)

                cv2.rectangle(frame, (x, y), (x+w, y+h), (0, 255, 0), 2)
                cv2.putText(
                    frame,
                    f"{emotion} ({conf:.2f})",
                    (x, y - 10),
                    cv2.FONT_HERSHEY_SIMPLEX,
                    0.8,
                    (0, 255, 0),
                    2
                )

            cv2.imshow(
                "Realtime Facial Emotion Recognition (Vietnamese Faces)",
                frame
            )

            if cv2.waitKey(1) & 0xFF == ord("q"):
                break

        self.cap.release()
        cv2.destroyAllWindows()
